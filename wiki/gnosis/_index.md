# Gnosis Index

Navigation: [[index]] | [[sources/_index|Sources]] | [[hot]]

Gnosis is a decision-intelligence and decision-ledger platform for buy-side asset managers. Every investment decision runs through a seven-phase lifecycle (propose, capture, evaluate policy, exception, approve, link precedent, commit) on an append-only event store with bitemporal replay, hard info-barrier and conflict-of-interest gates, maker-checker approvals, five precedent matchers, a validated recommendation engine, a read-only chat agent that logs tool calls as lineage, and an MCP server.
